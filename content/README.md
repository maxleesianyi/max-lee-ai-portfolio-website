# Editing Your Portfolio Content

Edit `content/site.json` when you want to update the website without touching code.

## What You Can Change

- Homepage hero copy and social links
- About Me page
- AI at Work stories
- Project titles, summaries, case study text, metrics, tags, and highlights
- Work experience at the bottom of the homepage
- Footer text and email address

## Simple Rules

- Keep the quotation marks around text.
- Keep commas between items.
- Do not delete field names like `"title"`, `"summary"`, or `"projects"`.
- Use the existing project blocks as templates when adding a new project.
- Keep each `slug` lowercase, with words separated by hyphens, such as `"my-new-project"`.

## Project Accent Colors

The current design supports these accent values:

- `gold`
- `teal`
- `blue`
- `red`
- `violet`

## Easiest Workflow

1. Open `content/site.json`.
2. Edit the words you want to change.
3. Ask Codex: "Please publish my latest portfolio edits."

Codex can check the file, fix any formatting mistakes, and publish the site.
